# Memory Replay - Backend

회상 엔진. Solar Pro 4 연동은 추후 별도 이슈로 진행한다.

## 책임
- 세션 생성/조회/삭제
- 단계별 상태 관리(SPLASH → COMPLETE)
- 빠른 메모 원문 보존
- 후보 추출 요청 처리(Solar 연동 전 목업/인터페이스 먼저 정의)
- 회상 질문 생성 요청 처리(추후 Solar 연동)
- 결과 생성(Markdown 우선, PDF는 추후)
- 데이터 삭제 및 자동 삭제 관리

## 데이터 격리
- 세션별 저장 영역 분리
- 원문, 중간 추출물, 결과를 함께 관리하되 불필요한 식별정보를 남기지 않는다.
- 로그에는 원문/첨부내용을 남기지 않는다.

## 보안
- Solar API 키는 서버에서만 사용한다.
- 프론트에는 키를 노출하지 않는다.
- 파일명/다운로드명에서 위험한 문자를 제거한다.
