- 참가자: {나} + {상대 인원·역할 짐작(확실한 범위만)}

## 2. 타임라인
표 머리: # / 무슨 일 / 나의 답 (첫 문장) / 상대 반응 / 확신도 / 출처: 서술·단서·역순·D+1

## 3. 갭 분석 (봉인 해제한 뒤)
- ✅ 준비했고 나옴: (항목 나열)
- ⬜ 나왔는데 준비 없음: (항목 나열)
- ○ 준비했지만 안 나옴: (항목 나열)
- 준비 자료 유무: 있음 / 없음 → 없음이면 "준비 여부: 사용자 기억 기준"
- (사건엔 대조할 정답이 없음 — "틀렸다"는 표현 쓰지 않음)

## 4. 분리한 평가 문장
사용자가 사실 회상 중 남긴 평가어("망했다" 등)를 여기 따로 적고, 다시 사실 회상으로 복귀한 시점도 함께 남긴다.

- ③ 원인: (왜 그렇게 됐다고 보는지)
- ④ 유지/개선
  - 유지(잘된 것 최소 1개):
  - 개선:

- 답란은 아랫줄에 분리해서 제시.
