# 메멘토 · Memento

**면접 직후의 기억을 되짚고 정리하는 AI 복기 서비스**

메멘토는 녹취가 없는 면접 직후, 취업준비생이 기억나는 질문과 답변을 남기고 단계별 질문을 통해 복기하도록 돕습니다.

AI가 빈 기억을 추측해서 채우지 않고, 사용자가 확인한 기억과 불확실한 내용, 평가·감정을 구분해 복기노트로 정리하는 것을 목표로 합니다.

## 핵심 기능

- **빠른 메모:** 떠오르는 내용을 자유롭게 기록
- **후보 검증:** AI가 추출한 내용을 O / X / ? / 수정 / ‘이런 내용 없음’으로 확인
- **추가 회상:** 맥락·시간·공간·행동 단서와 역순 회상으로 기억 되짚기
- **타임라인 검토:** 기억의 순서·내용·확신도를 사용자가 확인
- **복기 결과:** 복기노트와 근거에 기반한 연습 자료 생성
- **기록 관리:** 면접별 아카이브와 휴지통·복구

위 항목은 목표 기능이며, 현재 구현 범위는 아래 개발 상태를 참고하세요.

## 목표 사용자 흐름

```text
서비스 진입
→ 빠른 메모 · 텍스트/사진
→ 기억 후보 추출
→ 사용자 검증
→ 잡포스팅 URL 입력 · 선택
→ 면접 기본 정보
→ 추가 회상
→ 타임라인 검토
→ 복기 결과
→ 아카이브
```

면접 직후 복기에 집중하며, 별도의 상황 선택 단계는 두지 않습니다.

## 회상 원칙

1. 사용자가 제공하지 않은 사건 내용을 만들어 넣지 않습니다.
2. 거절한 후보는 이후 질문·요약·결과의 전제로 사용하지 않습니다.
3. 불확실한 기억을 확실한 사실로 바꾸지 않습니다.
4. 실제로 기억하는 내용과 평가·감정·추측을 분리합니다.
5. 한 번에 회상 질문 하나를 제시하고, 모름·넘기기·중도 종료를 허용합니다.

결과는 사용자의 기억을 구조화한 기록이며, 녹취나 객관적인 사실 확인 결과가 아닙니다.

## 입력 자료의 구분

- **빠른 메모용 사진:** Document Parse로 텍스트를 추출하고, 사용자 검증을 거쳐 회상 입력으로 활용합니다.
- **잡포스팅:** 선택적 배경 자료입니다. 공고의 내용을 실제 면접에서 나온 질문이나 사건으로 취급하지 않습니다.
- **면접 준비자료:** 회상 검토 완료와 사용자 대조 동의 후에만 열어 별도로 비교합니다.

## 대표 스킬과 서비스 확장

예선 대표 스킬 `memory-replay`를 핵심 회상 및 결과 생성 로직으로 연결할 계획입니다.

기존 회상 절차를 유지하면서 서비스 모드의 단계 제어, 후보 검증, 사진 입력, 결과 관리 기능을 확장합니다. 일반 모드와 서비스 모드의 차이 및 변경·고도화 내역은 PRD 스킬 매핑에 기록합니다.

현재 이 저장소에는 스킬 패키지와 실제 호출 연결이 아직 반영되지 않았습니다.

## 현재 개발 상태

기본 브랜치 확인 기준: `2419cbe`

- 스플래시·상황 선택·빠른 메모의 초기 컴포넌트
- 프론트 상태 훅과 로컬 저장 유틸리티
- 백엔드 목업 데이터와 API 인터페이스 초안

현재 코드는 초기 스켈레톤입니다. 상황 선택 등 이전 흐름이 남아 있으며, 최신 흐름으로 정리가 필요합니다. 전체 사용자 흐름과 실제 AI 호출은 아직 연결되지 않았습니다.

## 개발 우선순위

### P0 · 핵심 흐름 연결

- 프론트 실행 진입점과 화면 연결 정리
- 상황 선택 제거 및 면접 전용 흐름 반영
- 대표 스킬 패키지와 백엔드 호출 연결
- 빠른 메모·후보 추출·사용자 검증
- 선택적 잡포스팅·면접 기본 정보
- 추가 회상·타임라인 검토·Markdown 결과

### P1 · 입력과 사용 안정성

- 사진 업로드·Document Parse
- 준비자료 접근 통제
- 입력 보존·오류 복구·응답 검사
- 모바일 사용성
- 아카이브·휴지통 30일 보존·기간 내 복구

### 검토 항목

- PDF 다운로드
- 받아쓰기용 음성 기능
- D+1 추가 회상 안내

미확정 기능은 별도 검토 후 구현 범위에 반영합니다.

## 개발 환경

프론트 설정은 Next.js 14와 React 18 기반이며 Node.js 20 이상을 사용합니다.

```bash
git clone https://github.com/hge7317/memento_upstage2026.git
cd memento_upstage2026/frontend
npm install
npm run dev
```

위 명령은 현재 package.json에 정의된 개발 명령입니다. 시작 페이지와 컴포넌트 연결을 정리해야 하며, 정상 실행 검증은 아직 완료되지 않았습니다.

백엔드는 실행 서버가 아닌 목업 단계입니다.

## Solar 연동 계획

- Solar Pro 4 호출은 백엔드에서 처리합니다.
- API 키를 브라우저 코드에 포함하지 않습니다.
- 대표 스킬과 필요한 참조 문서를 명시적으로 로딩합니다.
- 서비스가 현재 단계·검증 상태·자료 접근을 관리하고, AI 응답을 검사한 뒤 다음 단계로 이동합니다.
- 실제 스킬 호출과 결과 생성은 코드 및 실행 로그로 검증합니다.
