# 코드 리뷰 체크리스트

PR을 검토할 때 아래 항목을 확인한다.

## 공통

- [ ] PR 제목과 본문이 템플릿에 맞게 작성됨
- [ ] 변경의 목적이 명확함
- [ ] 한 PR에 관련 없는 변경이 섞여 있지 않음
- [ ] 커밋 이력이 깔끔하고 불필요한 디버깅 커밋이 남아 있지 않음
- [ ] 민감정보(키, 토큰, 사용자 원문 예시 등)가 코드에 노출되지 않음

## 기능

- [ ] PRD v0.2의 해당 기능 요구사항을 만족함
- [ ] 사용자 원문·중간 추출물·결과가 적절히 격리됨
- [ ] 원문 유실, 상태 꼬임, 단계 건너뛰기 가능성이 검토됨
- [ ] 오류·네트워크 실패·파일 생성 실패 시 폴백이 있음
- [ ] 삭제 후 재접근 불가가 보장됨

## UX/품질

- [ ] 모바일에서 주요 흐름이 한 손 조작에 무리가 없음
- [ ] 질문이 한 번에 하나씩만 노출됨
- [ ] 미언급 명사, X 후보 전제 사용, 평가 혼입이 발생하지 않도록 처리됨
- [ ] 불확실·모름·넘기기가 정상 경로로 처리됨
- [ ] 결과 화면과 다운로드 결과(Markdown/PDF)가 일치함

## 문서

- [ ] 변경된 동작이 README/가이드/UX 문구에 반영됨
- [ ] 상태 모델이나 규칙 변경이 있으면 PRD 관련 절과 정합성이 맞음
