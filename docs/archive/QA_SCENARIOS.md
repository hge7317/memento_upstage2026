# QA 시나리오

PRD v0.2 18절을 기준으로 관리한다. 새 기능 추가 시 관련 시나리오를 함께 점검한다.

## 공통
- [ ] 단어만 나열한 빠른 메모에서도 후보 카드가 생성된다
- [ ] "아마"가 포함된 문장은 불확실 후보로 유지된다
- [ ] AI가 원문에 없는 고유명사를 후보에 추가하지 않는다
- [ ] X 처리된 후보가 이후 질문과 결과에 나타나지 않는다
- [ ] 수정한 후보는 수정 원문과 출처를 유지한다
- [ ] 모든 후보를 ?로 처리해도 복기를 계속할 수 있다
- [ ] 질문은 항상 하나씩 표시된다
- [ ] "모름"을 선택해도 오류나 실패로 표시되지 않는다
- [ ] 중도 종료해도 현재까지의 결과를 받을 수 있다
- [ ] Markdown과 PDF 내용이 화면 결과와 일치한다

## 면접
- [ ] 회사명을 비공개로 두어도 진행 가능하다
- [ ] 사용자가 기술 질문을 말하지 않았다면 AI가 기술 질문을 제시하지 않는다
- [ ] "망한 것 같다"는 평가 영역으로 분리된다
- [ ] 질문·답변·관찰된 반응이 서로 다른 필드에 저장된다
- [ ] 준비자료가 없다면 갭 분석을 억지로 생성하지 않는다

## 분실물
- [ ] 마지막 확실한 확인과 추정 구간이 분리된다
- [ ] AI가 특정 장소를 실제 위치로 단정하지 않는다
- [ ] 사용자가 언급하지 않은 사람을 의심하게 만들지 않는다
- [ ] 민감 물품에는 기억 결과와 분리된 안전 조치가 표시된다
- [ ] 확인 순서는 안전성·미확인 여부·마지막 접촉 근접성을 근거로 보여준다

## 미팅
- [ ] 결정과 제안이 분리된다
- [ ] 담당자·기한이 기억나지 않으면 "[확인 필요]"로 남는다
- [ ] 숫자와 날짜의 불확실성이 보존된다
- [ ] 참석자의 의도 추정은 개인 해석으로 분리된다
- [ ] 액션 아이템마다 출처와 확신도가 표시된다
