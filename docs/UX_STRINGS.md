# UX 문구 관리

PRD v0.2 13절을 기준으로 관리한다. 화면 추가/수정 시 함께 갱신한다.

## 스플래시
- 제목: 기억이 흐려지기 전에, 먼저 적어 두세요
- 설명: AI가 내용을 대신 만들지 않습니다. 당신이 확인한 기억을 바탕으로 더 잘 떠올리도록 질문합니다.

## 상황 선택
- 제목: 어떤 일을 복기할까요?
- 탭: 면접 복기 / 분실물 찾기 / 미팅 복기
- 보조 문구: 상황에 따라 질문과 결과 형식이 달라집니다.

## 빠른 메모
- 제목: 지금 바로 떠오르는 것부터
- 설명: 정리하지 말고 그대로 적어 주세요. 단어만 써도 됩니다.

## O/X 검증
- 제목: 제가 이해한 내용이 맞나요?
- 설명: 맞지 않는 내용은 반드시 X 또는 수정해 주세요. 확인 전에는 사실로 사용하지 않습니다.

## Step 2
- 제목: 기억을 차근차근 되짚어 볼게요
- 상시 동작: 모름 / 넘기기 / 현재 내용으로 끝내기

## 결과 상단 고지
- 이 문서는 사용자의 기억을 구조화한 기록입니다. 녹취나 객관적 사실 확인 결과가 아니며, AI가 정확성을 보증하지 않습니다.

## 금지 UX
- 기억이 안 난다는 이유로 경고/실패/낮은 점수를 표시하지 않는다.
- 질문 수를 게임 점수처럼 표현하지 않는다.
- AI 후보를 체크된 정답처럼 미리 보여주지 않는다.
- 확신도를 정확도 점수처럼 시각화하지 않는다.
- 분실물 위치나 면접 결과를 확률로 예측하지 않는다.
