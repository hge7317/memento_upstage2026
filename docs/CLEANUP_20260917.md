## 코드 구조

- 활성 앱을 `frontend-v5`로 통일하고 배포 루트 이름은 유지했습니다.
- App에서 세션·기록 상태를 `hooks/useMemorySession.js`, 기록 변경 규칙을 `lib/records.js`로 분리했습니다.
- 공통 JSON API 전송을 `lib/api.js`로 모으고 실패 시 타이머 해제를 보장했습니다. 공고 요청에도 30초 제한을 적용했습니다.
- 회상 단계 정의와 후보 분류를 `lib/recall.js`로 분리했습니다.
- 3,181줄 CSS를 화면별 파일로 분리했습니다. import 순서와 내용은 유지했습니다.
- Express 앱 구성, 서버 시작, 두 API 처리기, Solar 클라이언트를 분리했습니다. Vercel import 시 로컬 서버가 시작되지 않습니다.
- 사용하지 않는 목업 모듈·상수·콜백과 `node-fetch` 의존성을 제거했습니다.
- 루트 빌드·테스트 명령, 환경 변수 예시, 실행 안내와 AGENTS를 현재 구조에 맞췄습니다.

- 실제 인증과 DB 저장: 현재 데모 로그인, React 메모리 기록입니다.

- API 실패 시 정적 회상 질문으로 대체됩니다.
